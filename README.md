# 🛒 Walmart Sales Data Analysis (SQL Project)

## 📌 Project Overview
Analyzed Walmart sales dataset using SQL to extract insights on sales trends, customer behavior, and business performance.

---

## 🛠 Tools Used
- SQL (MySQL)
- Excel

---

## 📊 Key Analysis
- Identified top-selling products and categories  
- Analyzed sales trends by branch, city, and day  
- Found most used payment methods  
- Ranked best-performing branches using window functions  
- Calculated total profit by category  

---

## 💡 Key Insights
- Certain branches generate higher revenue during weekends  
- E-wallet and cash are the most preferred payment methods  
- Some product categories contribute significantly to total profit  

---

## 🧠 SQL Concepts Used
- GROUP BY, HAVING  
- JOINS  
- Window Functions (RANK)  
- CTE (Common Table Expressions)  
- Aggregate Functions (SUM, AVG)  

---

## 📁 Files in Repository
- `walmart_dataset.csv` → Raw dataset  
- `queries.sql` → SQL queries for analysis  

---

## 🚀 Conclusion
This project demonstrates how SQL can be used to analyze retail data and generate actionable business insights.
